Ridge Runner: Valley Air Mail — fly the Kestrel K-2 bush plane through a procedural mountain valley: thread glowing signal rings, deliver air mail to remote strips, and land back on the runway. A complete offline flight game in static files: chase and cockpit views over recognisable terrain, a built-up aircraft with lit instruments, a HUD showing altitude, speed and heading, fuel and airframe damage that turn every sortie into decisions, and three missions with different goals.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and fly with the arrow keys (Shift/Ctrl for throttle, C for cockpit view, P to pause). No network requests, no build step: `game/` is plain static files.
